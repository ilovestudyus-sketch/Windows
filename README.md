# Windows

这里只放 ILovestudy 节点分析工具的 Windows 安装包，以及一次连接检查。

不含源码，不含订阅。订阅只放在本仓库的 Actions Secret `R9_TEST_SUBSCRIPTIONS`。检查脚本不会把订阅地址或正文写进日志。每次检查结束都会删除临时订阅文件、解压出来的安装包，以及 `%LOCALAPPDATA%\ILovestudy`。

手动运行：Actions →「Windows 安装包连接检查」→ Run workflow。

安装包来自已经通过 Windows 门禁的 `0.4.3-test22`，SHA-256 `595cb5a1c44a97c6b9b2a5a2d9b659ec6e69bd75c0da5749d39506a4b81b09fb`。
